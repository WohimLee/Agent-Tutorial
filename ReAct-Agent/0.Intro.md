### 二、知识模块
#### 2.1 第一类：State 的创建与管理

State 是 Graph 中流动的信息载体，定义了数据的结构和存储方式。作为 AI Agent 工作流建模的形式，Graph 的核心在于将与 model 交互产生的信息（最典型的如 messages）保存在 state 中，从而实现对话历史的管理（实现 short-term memory）和上下文的传递等功能。

##### 基础层：State 的基本概念和使用

参考文章：

1. 从零开始学 LangGraph（4）：用 Excel 表格来理解 LangGraph 的基本工作原理
2. 从零开始学 LangGraph（9）：详解 State 的定义、更新与管理

State Schema 可以用以下方式定义：

* TypedDict
* Pydantic Model
* dataclass

TypedDict 轻量、无需额外依赖，但只提供类型提示，不进行运行时校验。
Pydantic Model 提供运行时验证、默认值、字段约束等能力，更适合构建健壮的 Agent。

---

##### 应用层：State 的更新机制与短期记忆实现

参考文章：

1. 从零开始学 LangGraph（9）：详解 State 的定义、更新与管理
2. 从零开始学 LangGraph（7）：手把手教你手搓带 Memory 的 Chat Bot

State 更新是一个**两阶段过程**：

1. Node 函数返回需要更新的字段和值
2. Reducer 决定如何合并（覆盖 / 拼接 / 累加等）

常见 Reducer：

* `add_messages`：消息累积
* `operator.add`：数值累加
* `operator.extend`：列表扩展

当需要强制覆盖时，可使用 **Overwrite** 机制。

通过 `messages + add_messages`，即可实现 Agent 的短期记忆能力。
