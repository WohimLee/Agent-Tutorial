## 🧩 这个库是什么？

`mcp` 是 **MCP 的 Reference Python Implementation**，它同时包含：

| 能力         | 说明                          |
| ---------- | --------------------------- |
| MCP Server | 你可以用它写 MCP server           |
| MCP Client | 你可以让 Python 程序连接 MCP server |
| Transport  | stdio / http                |
| Protocol   | tools, resources, prompts   |
| JSON-RPC   | MCP 的底层通信实现                 |

它不是 wrapper，而是 **协议本体级实现**。

---

## 🛠 一个最小 MCP Server（官方写法）

```python
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("math")

@mcp.tool()
def add(a: int, b: int) -> int:
    return a + b

if __name__ == "__main__":
    mcp.run()
```

Claude Desktop / Cursor / Windsurf 都可以直接连接这个 server。

---

## 🧪 MCP Client 示例

```python
from mcp.client import Client

client = Client("stdio://python server.py")
tools = client.list_tools()
print(tools)
```

## 🧬 这和 LangChain / OpenAI tools 有什么区别？

| MCP  | OpenAI tools / LangChain             |
| ---- | ------------------------------------ |
| 协议   | 是跨模型的协议                              |
| 传输   | stdio / http                         |
| 工具   | 独立进程                                 |
| 模型   | Claude、Cursor、Windsurf、未来 OpenAI 都能用 |
| 生命周期 | 工具可常驻                                |
| 安全   | 明确的 sandbox                          |

MCP 是 **“操作系统级别的工具总线”**
而不是某个框架的私有 API。
