## LangGraph
### 一、LangGraph 的核心组件（Core Components）
>1️⃣ Graph（图）

- 整个应用的顶层结构
- 本质是一个 有向图（Directed Graph）
- 用来组织节点、边、状态流转
- 👉 类似「流程引擎 + 状态机」
```py
from langgraph.graph import StateGraph
graph = StateGraph(State)
```

> 2️⃣ Node（节点）

- 图中的执行单元
- 本质是一个 函数 / Runnable
- 接收当前状态 → 返回更新后的状态
- 👉 Node ≈ LangChain 中的 Chain / Runnable

```py
def node_fn(state):
    return {"key": new_value}

graph.add_node("node_name", node_fn)
```


>3️⃣ Edge（边）

- 决定 执行顺序
- 分为两种：
    - 普通边（固定顺序）
    - 条件边（根据状态动态跳转）
```py
graph.add_edge("a", "b")
```
>4️⃣ Conditional Edge（条件边）

- 用于 if / else / switch
- 根据状态决定下一步去哪
- 👉 Agent 路由、决策核心

```py
graph.add_conditional_edges(
    "router",
    condition_fn,
    {
        "tool": "tool_node",
        "end": END
    }
)
```


>5️⃣ State（状态）

- LangGraph 的灵魂
- 所有节点共享、不断演化的状态

通常用 TypedDict / BaseModel 定义：
```py
from typing import TypedDict, List

class State(TypedDict):
    messages: List[str]
    step: int
```

特点：显式、可追踪、可回放、可中断

>6️⃣ Entry / END

- set_entry_point()：起点
- END：终止节点
```py
graph.set_entry_point("start")
graph.add_edge("final", END)
```
>7️⃣ Compiled Graph（可执行图）

- 图定义完成后，需要 compile
- 生成可运行对象
```py
app = graph.compile()
result = app.invoke(initial_state)
```
### 二、LangGraph 的核心概念（非常重要）
>🔁 1️⃣ 有状态执行（Stateful Execution）

- 不同于 LangChain「一步一步链式」
- LangGraph 每一步都显式读取 / 更新状态

    ✔ 可回溯
    ✔ 可暂停
    ✔ 可恢复
    ✔ 可调试

>🔄 2️⃣ 循环（Loop）

- LangGraph 原生支持循环
- 用途：ReAct Agent、多轮思考、工具反复调用

```py
graph.add_edge("agent", "agent")
```


>🧠 3️⃣ Agent = Graph

- 在 LangGraph 中：Agent 不是类，而是一张图

典型 Agent 结构：
```
┌───────┐
│ Agent │
└───┬───┘
    ↓
┌────────┐
│ Router │
└───┬────┘
  ┌─┴─┐
Tool  END
```

>🧩 4️⃣ 多 Agent（Multi-Agent）

- 每个 Agent = 子图
- Agent 之间通过 共享状态或消息通信
- 适合：规划 Agent、执行 Agent、审核 Agent

>🛑 5️⃣ 中断 & 人类介入（Human-in-the-loop）

- 支持：breakpoint、人工修改 state、再继续执行
- 非常适合：审批流、复杂决策系统

### 三、LangGraph 的执行机制（一步一步）

- 从 Entry 节点开始
- 执行当前节点函数
- 合并返回的 state
- 根据 edge / conditional edge 决定下一个节点
- 到达 END 或无可执行节点

### 四、与 LangChain 的关系（容易混）
- 👉 LangGraph 是 LangChain 的「控制层」

| LangChain        | LangGraph |
| ---------------- | --------- |
| Chain / Runnable | Node      |
| 顺序执行             | 图执行       |
| 隐式状态             | 显式状态      |
| 不支持循环            | 原生支持      |
| 单 Agent          | 多 Agent   |


### 五、适合用 LangGraph 的场景

✔ Agent（ReAct / Tool Agent）
✔ 多轮对话系统
✔ 工作流编排（Workflow）
✔ 多 Agent 协作
✔ 需要中断、回放、审计的系统
