>多 Agent 项目通用、简洁目录结构

* 多 Agent（agents）
* 记忆功能 & 数据库（memory / db）
* function_call / tools
* MCP（Model Context Protocol）

你可以按需删减或细化。

```bash
my-multi-agent-app/
├─ pyproject.toml          # 或 setup.cfg / requirements.txt：依赖 & 项目信息
├─ README.md               # 项目说明、运行方式
├─ .env.example            # 环境变量示例（API Key, DB 连接等）
├─ .gitignore
└─ src/
   └─ app/
      ├─ __init__.py

      # 1. 入口 & 配置
      ├─ main.py           # 程序入口（CLI / Web / Worker）
      ├─ config.py         # 全局配置加载（env, 常量）
      ├─ logging_config.py # 日志配置（可选）

      # 2. LangGraph 图 & 流程
      ├─ graphs/
      │   ├─ __init__.py
      │   ├─ core_graph.py       # 主业务图（路由、控制流程）
      │   ├─ subgraph_planning.py# 规划子图（Planner / Router）
      │   └─ subgraph_toolcall.py# 工具调用 / function_call 子图等

      # 3. Agent 定义
      ├─ agents/
      │   ├─ __init__.py
      │   ├─ base.py             # 抽象基类：统一 agent 接口
      │   ├─ planner_agent.py    # 负责任务规划/路由的 Agent
      │   ├─ worker_agent.py     # 执行任务的 Agent（可有多个类型）
      │   └─ supervisor_agent.py # 监督 / 纠错 / 总控 Agent（可选）

      # 4. 工具 / function_call / 外部能力
      ├─ tools/
      │   ├─ __init__.py
      │   ├─ base.py             # 通用 tool 基类 / 注册装饰器
      │   ├─ search_tools.py     # 示例：网络搜索、知识库查询
      │   ├─ system_tools.py     # 示例：时间、文件等系统工具
      │   └─ business_tools.py   # 业务相关工具（数据库写入、调用内部服务等）

      # 5. 记忆 & 数据层（短期/长期记忆、缓存、向量库）
      ├─ memory/
      │   ├─ __init__.py
      │   ├─ schemas.py          # 记忆/对话记录的数据结构定义
      │   ├─ memory_store.py     # 封装对记忆的读写接口（统一调用）
      │   ├─ short_term.py       # 短期记忆实现（会话缓存 / LangGraph state）
      │   └─ long_term.py        # 长期记忆实现（向量数据库 / SQL / NoSQL）

      ├─ db/
      │   ├─ __init__.py
      │   ├─ models.py           # ORM 模型(如 SQLAlchemy)或原始表结构
      │   ├─ session.py          # 数据库连接 & 会话管理
      │   └─ migrations/         # 数据库迁移脚本（可选）

      # 6. MCP 相关
      ├─ mcp/
      │   ├─ __init__.py
      │   ├─ servers/            # 你实现的 MCP servers
      │   │   ├─ __init__.py
      │   │   ├─ file_server.py  # 示例：文件/文档 MCP Server
      │   │   └─ service_x.py    # 其他服务的 MCP Server
      │   └─ clients/            # 访问外部 MCP server 的客户端封装
      │       ├─ __init__.py
      │       └─ mcp_client.py

      # 7. 接口层（可选：HTTP API / Web UI / CLI）
      ├─ interfaces/
      │   ├─ __init__.py
      │   ├─ api_http.py         # FastAPI / Flask 等 HTTP 接口
      │   ├─ cli.py              # 命令行入口 / 调试工具
      │   └─ adapters.py         # 将外部请求封装成 graph 输入/输出

      # 8. 公共工具 & 类型
      ├─ utils/
      │   ├─ __init__.py
      │   ├─ types.py            # 通用类型定义（state、pydantic 模型等）
      │   ├─ helpers.py          # 杂项工具函数
      │   └─ validators.py       # 数据校验、清洗（可选）

      # 9. 测试
      └─ tests/
          ├─ __init__.py
          ├─ test_graphs.py
          ├─ test_agents.py
          ├─ test_memory.py
          └─ test_tools.py
```

---

### 简要说明（按你关心的点）

* **LangGraph 图**：`graphs/`

  * `core_graph.py` 放主流程：如何在多个 Agent 间路由，何处读写记忆、调用工具等。
  * 子图拆小：比如规划子图、工具调用子图，更易复用和测试。

* **多 Agent**：`agents/`

  * 每个 Agent 一个文件，继承 `base.py` 中的抽象类或统一接口（如 `run(task, state)`）。
  * 方便在图里按名字引用 Agent。

* **记忆 / 数据库**：`memory/` + `db/`

  * 上层只用 `memory_store.py` 暴露的接口：`save_memory() / retrieve_memory()`。
  * 具体落地在 `db/`（SQL / 向量库 / KV 等），换实现时上层不用改。

* **function_call / Tools**：`tools/`

  * 把所有可被 LLM 调用的函数统一放在这里，并加元数据（schema、描述）。
  * LangGraph / OpenAI function calling / MCP 都可以从这里注册/复用。

* **MCP**：`mcp/servers` & `mcp/clients`

  * 服务器端：把你的内部能力包装成 MCP server，供外部或本项目 Agent 调用。
  * 客户端：连接外部 MCP servers（文件系统、浏览器、内部服务等）。
