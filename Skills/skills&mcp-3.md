## 一、为什么一定要拆成两种买家？

### 1️⃣ 公司买家的“风险核心”

* 假官网
* 没有真实采购能力
* 行业不匹配

👉 所以公司买家：**“业务与交易真实性优先”**

---

### 2️⃣ 个人买家的“风险核心”

> **这个人是不是对的人？有没有决策权？是不是冒名顶替？**

风险来源：

* 职位造假
* 身份混淆（同名）
* 外包 / 中介 / 无决策权
* 钓鱼式询盘

👉 所以个人买家：**“身份、角色、影响力优先”**

### Skill 2：职业与职位核验

`Role_Position_Verification_Skill`

`Professional_Background_Skill`

### Skill 4：社交影响力与活跃度

`Social_Influence_Activity_Skill`

**核验点**

* 互动质量（不是点赞数量）

👉 判断的是：
**“他是信息节点，还是路人账号”**

### Skill 5：沟通风格与合作偏好推断

`Communication_Preference_Skill`
