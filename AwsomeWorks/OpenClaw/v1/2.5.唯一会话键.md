## 唯一会话键

一旦 Agent 确定下来，系统就会为这次对话构建 sessionKey，格式一般是：
```ts
{agentId}:{scope}
```
比如：
```ts
assistant:main
assistant:whatsapp:direct:+1234567890
assistant:discord:channel:987654321
support:telegram:group:-1001234567890
```
这个键非常重要，因为它后面承担两件事：**会话隔离** 与 **并发控制**。

也就是说，用户看到的只是一句消息，但系统真正管理的，其实是：这句话属于 **哪个 Agent** 的 **哪一条会话**。
