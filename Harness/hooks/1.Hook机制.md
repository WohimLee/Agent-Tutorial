## Hook 机制

Hook（钩子）本质上是：**在某个流程的关键节点，预留一个可插入自定义逻辑的位置**。

在 LLM / Agent 里，Hook 常用于：记录日志、改写 prompt、拦截工具调用、做权限检查、统计 token、加缓存、观测推理过程、失败重试等。

## 1. Hook 的核心思想

假设一个 Agent 流程是：

```text
用户输入
  ↓
构造 Prompt
  ↓
调用 LLM
  ↓
解析结果
  ↓
调用工具
  ↓
返回答案
```

Hook 就是在这些节点前后插入逻辑：

```text
用户输入
  ↓
[before_prompt_hook]
构造 Prompt
[after_prompt_hook]
  ↓
[before_llm_hook]
调用 LLM
[after_llm_hook]
  ↓
[before_tool_hook]
调用工具
[after_tool_hook]
  ↓
[final_response_hook]
返回答案
```

## 2. 一个最小 Hook 示例

```python
class Agent:
    def __init__(self):
        self.hooks = {
            "before_llm": [],
            "after_llm": [],
        }

    def add_hook(self, event, fn):
        self.hooks[event].append(fn)

    def run_hooks(self, event, context):
        for fn in self.hooks.get(event, []):
            fn(context)

    def run(self, user_input):
        context = {
            "user_input": user_input,
            "prompt": f"请回答用户问题：{user_input}",
            "llm_response": None,
        }

        self.run_hooks("before_llm", context)

        # 模拟 LLM 调用
        context["llm_response"] = f"这是对「{context['prompt']}」的回答"

        self.run_hooks("after_llm", context)

        return context["llm_response"]
```

添加 Hook：

```python
def log_prompt(context):
    print("[LOG] Prompt:", context["prompt"])

def log_response(context):
    print("[LOG] Response:", context["llm_response"])

agent = Agent()
agent.add_hook("before_llm", log_prompt)
agent.add_hook("after_llm", log_response)

result = agent.run("什么是 RAG？")
print(result)
```

## 3. Hook 在 LLM/Agent 中的常见类型

### before_prompt：改写输入

```python
def add_system_instruction(context):
    context["prompt"] = (
        "你是一个严谨的 AI 助手，请分步骤回答。\n\n"
        + context["prompt"]
    )
```

用途：

```text
统一加系统提示词
注入用户画像
添加安全规则
添加输出格式要求
```

---

### before_llm：调用模型前拦截

```python
def block_sensitive_request(context):
    if "破解密码" in context["user_input"]:
        raise ValueError("该请求不允许处理")
```

用途：

```text
安全检查
权限验证
Prompt 注入检测
缓存命中检查
```

---

### after_llm：模型返回后处理

```python
def clean_response(context):
    context["llm_response"] = context["llm_response"].strip()
```

用途：

```text
格式化输出
提取 JSON
内容审核
记录 token 和 latency
```

---

### before_tool：工具调用前检查

```python
def check_tool_permission(context):
    tool_name = context.get("tool_name")

    if tool_name == "send_email":
        print("[CHECK] 即将发送邮件，需要确认权限")
```

用途：

```text
防止误发邮件
限制数据库写操作
审计工具调用
拦截危险工具
```

---

### after_tool：工具调用后增强

```python
def log_tool_result(context):
    print("[TOOL RESULT]", context.get("tool_result"))
```

用途：

```text
记录搜索结果
检测工具失败
自动重试
把工具结果压缩后再喂给 LLM
```

## 4. 一个更完整的 Agent Hook 示例

```python
class HookedAgent:
    def __init__(self, llm, tools=None):
        self.llm = llm
        self.tools = tools or {}
        self.hooks = {}

    def add_hook(self, event, fn):
        self.hooks.setdefault(event, []).append(fn)

    def run_hooks(self, event, context):
        for fn in self.hooks.get(event, []):
            fn(context)

    def run(self, user_input):
        context = {
            "user_input": user_input,
            "prompt": None,
            "llm_response": None,
            "tool_name": None,
            "tool_args": None,
            "tool_result": None,
        }

        self.run_hooks("before_prompt", context)

        context["prompt"] = context.get("prompt") or f"""
你是一个 Agent。
用户问题：{user_input}
请判断是否需要调用工具，并给出回答。
"""

        self.run_hooks("after_prompt", context)

        self.run_hooks("before_llm", context)
        context["llm_response"] = self.llm(context["prompt"])
        self.run_hooks("after_llm", context)

        return context["llm_response"]
```

模拟 LLM：

```python
def fake_llm(prompt):
    return "我会先分析问题，然后给出答案。"
```

加 Hook：

```python
agent = HookedAgent(llm=fake_llm)

agent.add_hook("before_prompt", lambda ctx: print("[输入]", ctx["user_input"]))

agent.add_hook("after_prompt", lambda ctx: print("[Prompt]", ctx["prompt"]))

agent.add_hook("after_llm", lambda ctx: print("[LLM返回]", ctx["llm_response"]))

print(agent.run("帮我解释一下 ReAct Agent"))
```

## 5. Hook 的高级用法：修改上下文

Hook 不只是“旁观”，也可以修改流程。

例如：自动给 LLM 加 JSON 输出要求。

```python
def force_json_output(context):
    context["prompt"] += """

请严格用 JSON 输出：
{
  "thought": "...",
  "answer": "..."
}
"""
```

使用：

```python
agent.add_hook("after_prompt", force_json_output)
```

这样所有请求都会被统一改成 JSON 输出格式。

## 6. Agent 工具调用 Hook 示例

```python
class ToolAgent:
    def __init__(self):
        self.hooks = {}
        self.tools = {
            "search": self.search_tool,
            "calculator": self.calculator_tool,
        }

    def add_hook(self, event, fn):
        self.hooks.setdefault(event, []).append(fn)

    def run_hooks(self, event, context):
        for fn in self.hooks.get(event, []):
            fn(context)

    def call_tool(self, tool_name, tool_args):
        context = {
            "tool_name": tool_name,
            "tool_args": tool_args,
            "tool_result": None,
        }

        self.run_hooks("before_tool", context)

        result = self.tools[tool_name](**context["tool_args"])
        context["tool_result"] = result

        self.run_hooks("after_tool", context)

        return context["tool_result"]

    def search_tool(self, query):
        return f"搜索结果：{query}"

    def calculator_tool(self, expression):
        return eval(expression)
```

添加工具调用审计：

```python
def audit_tool_call(context):
    print(f"[AUDIT] 调用工具：{context['tool_name']}")
    print(f"[AUDIT] 参数：{context['tool_args']}")

def block_dangerous_calculation(context):
    if context["tool_name"] == "calculator":
        expr = context["tool_args"].get("expression", "")
        if "__import__" in expr:
            raise ValueError("危险表达式，已拦截")

agent = ToolAgent()
agent.add_hook("before_tool", audit_tool_call)
agent.add_hook("before_tool", block_dangerous_calculation)

print(agent.call_tool("search", {"query": "LangChain hooks"}))
```

## 7. LLM/Agent 中 Hook 的典型应用

| Hook 场景     | 作用                         |
| ----------- | -------------------------- |
| Prompt Hook | 自动注入系统提示词、用户偏好、格式要求        |
| LLM Hook    | 记录请求、统计 token、缓存、限流        |
| Tool Hook   | 权限检查、审计日志、失败重试             |
| Memory Hook | 读取或写入长期记忆                  |
| RAG Hook    | 检索前改写 query，检索后重排文档        |
| Safety Hook | 检测越权、敏感内容、Prompt Injection |
| Eval Hook   | 收集模型输出，用于离线评估              |

## 9. Hook vs Callback vs Middleware

简单理解：

```text
Hook：某个生命周期点上的扩展函数
Callback：某件事发生后回调通知
Middleware：包在主逻辑外面的一层处理链
```

在 Agent 系统里，这三者经常混用。

例如：

```text
before_llm_hook ≈ callback
tool_middleware ≈ before_tool + after_tool hooks
```

## 10. 设计 Hook 时的最佳实践

第一，Hook 要接收统一的 `context` 对象。

```python
def my_hook(context):
    ...
```

第二，Hook 名称要围绕生命周期命名。

```text
before_prompt
after_prompt
before_llm
after_llm
before_tool
after_tool
on_error
on_finish
```

第三，Hook 不要做太多主流程逻辑。

Hook 适合做“横切逻辑”，比如日志、权限、监控、格式化，而不是把核心业务全塞进去。

第四，Hook 顺序要可控。

```python
agent.add_hook("before_llm", safety_check)
agent.add_hook("before_llm", logging_hook)
agent.add_hook("before_llm", cache_hook)
```

第五，错误要有专门的 Hook。

```python
def on_error(context):
    print("出错了：", context["error"])
```

## 11. 一个推荐的 Hook 架构

```python
class HookManager:
    def __init__(self):
        self._hooks = {}

    def register(self, event, fn, priority=100):
        self._hooks.setdefault(event, []).append((priority, fn))
        self._hooks[event].sort(key=lambda x: x[0])

    def emit(self, event, context):
        for _, fn in self._hooks.get(event, []):
            fn(context)
```

用法：

```python
hooks = HookManager()

hooks.register("before_llm", safety_check, priority=10)
hooks.register("before_llm", log_prompt, priority=50)
hooks.register("after_llm", clean_response, priority=20)

context = {"prompt": "解释 AI Agent"}
hooks.emit("before_llm", context)
```

## 12. 总结一句话

Hook 就是给 Agent 流程安装“插座”。

主流程负责跑：

```text
输入 → 推理 → 工具 → 输出
```

Hook 负责插入额外能力：

```text
日志、监控、安全、缓存、重试、格式化、记忆、评估
```

在 LLM/Agent 系统里，Hook 是做工程化、可观测性、安全控制和扩展能力的核心机制之一。
