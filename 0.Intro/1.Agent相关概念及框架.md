## Agent
### 一、什么是 Agent（智能体）

>一句话定义
- Agent 是一个能感知环境、做出决策并采取行动，以达成目标的自主系统。

>经典公式
- Agent = Perception（感知） + Decision（决策） + Action（行动）

在大模型时代，Agent 往往是：

- 以 LLM（大语言模型） 作为“大脑”
- 能使用 工具（Tools）
- 能 规划、执行、反思
- 能长期运行，而不只是“一问一答”

### 二、Agent 与普通 Chatbot 的区别
| 维度     | Chatbot   | Agent             |
| ------ | --------- | ----------------- |
| 是否有目标  | ❌ 通常没有    | ✅ 明确目标            |
| 是否持续运行 | ❌ 单轮/多轮对话 | ✅ 可长期运行           |
| 是否能行动  | ❌ 只生成文本   | ✅ 调用工具 / API / 系统 |
| 是否能规划  | ❌ 被动回答    | ✅ 主动拆解任务          |
| 是否能反思  | ❌ 很弱      | ✅ 可自我修正           |


👉 Agent = 会“做事”的模型，而不仅是“聊天”的模型

### 三、Agent 的核心组成模块
##### 1️⃣ 感知（Perception）

Agent 如何“看见”世界：
- 用户输入
- 文件（PDF、代码、表格）
- API 返回结果
- 传感器数据（机器人领域）

在 LLM Agent 中，本质是：把外部信息转成 Prompt / Context

##### 2️⃣ 记忆（Memory）

Agent 不只是“即时上下文”，而是有记忆：

常见记忆类型：
- 短期记忆：当前对话上下文（context window）
- 长期记忆：向量数据库（RAG）
- 情景记忆：过去的任务、经历
- 用户记忆：偏好、习惯

📌 记忆让 Agent 从“工具”进化为“伙伴”。

##### 3️⃣ 规划（Planning）

Agent 会把一个复杂目标拆解成步骤。

例如：

目标：写一份市场分析报告
→ 搜集数据
→ 分析趋势
→ 生成大纲
→ 撰写内容
→ 校对修改

常见规划方式：
- Chain of Thought（隐式）
- Task Decomposition（显式任务拆解）
- Tree of Thoughts
- ReAct（Reason + Act）

##### 4️⃣ 行动（Action / Tools）

Agent 能调用外部能力：
- 搜索（Web）
- 代码执行
- 数据库查询
- 调用 API
- 控制系统（自动化、机器人）

在工程上表现为：Function Calling / Tool Calling

这是 Agent 和 LLM 的“质变点”。

##### 5️⃣ 反思（Reflection）

高级 Agent 会：
- 检查结果是否正确
- 发现错误并修正
- 总结经验用于下次

例如：Self-Reflection、Critic Agent、Judge / Evaluator

📌 反思能力 ≈ 智能体“自我进化”的起点。

### 四、常见 Agent 类型
##### 🔹 1. 单 Agent

- 一个模型
- 一套工具
- 一个目标

适合：自动写代码、文档生成、数据分析

##### 🔹 2. 多 Agent（Multi-Agent）

多个 Agent 分工协作：

| Agent      | 角色    |
| ---------- | ----- |
| Planner    | 制定计划  |
| Executor   | 执行任务  |
| Critic     | 审查与纠错 |
| Researcher | 搜集信息  |


特点：
- 类似“虚拟团队”
- 通常通过消息传递协作

##### 🔹 3. Autonomous Agent（自治智能体）

特点：

- 几乎不需要人类介入
- 可长时间运行
- 主动发现任务

代表概念：Auto-GPT、BabyAGI、AutoGen

⚠️ 风险也最大（失控、循环、成本）
